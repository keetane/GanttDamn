## グリッドと項目の編集

左側の列見出しは初期状態で `milestone` / `action item` です。見出し・項目名・補足はダブルクリック、またはフォーカスして `Enter` で編集できます。隣接する同名のmilestoneは、同じPJ内で縦に結合します。空欄や離れた同名は結合しません。

結合セルの直接編集はグループ全体に適用します。各行を別の名前に変える場合は、対象行のaction itemや時間軸セルを選び、編集パネルで項目名を変更します。

| 操作 | 方法 |
|---|---|
| バー作成 | 時間軸セルをドラッグして選択し、パレットで色を指定 |
| 色・文字の編集 | バーを選び、パレットまたは編集パネルで変更 |
| バーの伸縮 | 左端・右端をドラッグ |
| 部分消去 | バーの中からドラッグで範囲を選び、「塗りつぶしを解除」またはDelete |
| 行選択 | 左側の項目列をクリック。Shiftクリックで複数行を選択 |
| 選択解除 | 選択中の項目・セル・バー・ダイヤモンドを再クリック |
| 行の並べ替え | 行番号をドラッグ、または編集パネルの上へ／下へ移動 |
| 行の複製・挿入・削除 | 編集パネルで操作 |
| 大きさの変更 | 行下端・列見出し右端をドラッグ、または表示設定で調整 |
| ダイヤモンド追加 | 空のセルを選び、編集パネルの「マイルストーンを追加」 |

同じ行を再塗りつぶしすると、既存のバーを分割・置換します。離れたバーは保持します。通常モードでは色付きセル・バー本体を横ドラッグすると、そのバーだけを移動できます。◆も横ドラッグで単独移動できます。バー内の部分選択はShift＋ドラッグ、範囲選択は空セルからドラッグし、一括移動にはDamn itモードを使います。all project nameの集約バーでは、そのPJの元のスケジュールをまとめて移動します。

セル表示はグリッド線を残した塗りつぶし、バー表示は横長の矩形です。どちらも同じスケジュールデータを使用します。

## キーボードと貼り付け

| 操作 | キー |
|---|---|
| 元に戻す | Cmd/Ctrl + Z |
| やり直す | Cmd/Ctrl + Shift + Z |
| 選択内容を消去 | Delete / Backspace |
| 直接編集を開始 | 編集可能な文字にフォーカスしてEnter |
| Damn itのドラッグを取消 | Esc |

Excelなどのタブ区切りテキストを貼り付けると、1列目を項目名、2列目を補足として読み込みます。選択行から貼り付け、未選択なら末尾へ追加します。入力欄の編集中はブラウザ標準のキー操作が優先されます。

## 時間軸・表示期間・稼働カレンダー

表示設定でPJ開始日・終了日を指定します。終了日はその日を含み、省略時は開始日から3年間です。開始日から終了日まで横スクロールでき、表示範囲や単位を変えてもバーに保存された日付は変わりません。

「表示期間」は1画面に表示する時間軸セルの数です。セル幅は画面幅に応じて計算します。時間軸を切り替えると、次の初期値に切り替わり、表示設定で調整できます。

| 時間軸 | 1セル | 初期表示期間 |
|---|---|---|
| 1時間 | 稼働時間内の1時間 | 12 |
| 日 | 稼働日1日 | 15 |
| 週 | 月曜開始の1週間 | 12 |
| 月 | 暦月 | 12 |
| Q | 暦年の四半期 | 8 |

稼働日の初期値は月〜金、稼働時間は8:00〜18:00（終了時刻を含まない）です。1時間・日は稼働カレンダーに従い、週・月・Qは暦ベースです。非稼働時間のデータは保持し、表示されるセルだけが変わります。

週が月をまたぐ場合は分割せず、週の開始日が属する月へまとめます。例えば4/26〜5/2は4月側に表示します。日表示には曜日も表示します。

## 日付線と「今日へ」

「日付線」で赤線を表示・非表示にできます。線には日付の文字を表示せず、左側の項目・補足列には重ねません。

営業時間中は現在位置、始業前は当日の開始、終業後や非稼働日は次の稼働開始を示します。既定のカレンダーなら、金曜18時以降や土日は月曜8時になります。

「今日へ」は同じ位置へスクロールし、日付線がオフならオンにします。移動先がPJ期間外なら通知し、PJ日付は変えません。時間軸やPJの切替時は、日付線のセルが時間軸の先頭に来るようにスクロールします。PJ終端ではスクロール可能な範囲に収まります。

## PJの管理と一覧

上部のプロジェクト選択で表示を切り替えます。「プロジェクト管理」では作成・名前変更・複製・削除・JSON読み込みができます。編集中の個別PJを削除する場合は、先に別の表示へ切り替えます。

| 表示 | 内容と編集範囲 |
|---|---|
| 個別PJ | 項目追加、名前・補足編集、バーの伸縮などの編集が可能 |
| `all` | 全PJの項目を表示。PJ間に黒線を引き、最下部には引かない |
| `all project name` | 1PJにつき1行。項目・補足列を隠し、スケジュールの最早開始〜最遅終了を1本のバーで表示。ダイヤモンドも同じ行に表示し、PJ区切り線は引かない |

一覧での集約表示は、元の項目名・補足・高さ・個々のバーを保持します。バー未登録のPJはダイヤモンドとPJ名だけを表示します。項目の追加・名称編集・バーの伸縮は個別PJへ切り替えて行います。

一覧の期間は全PJの開始日〜終了日を含み、時間軸と稼働カレンダーは一覧へ切り替える直前の表示を引き継ぎます。一覧の表示単位を変えても各PJの設定は変更しません。最後に選んだPJまたは一覧を再読み込み後も復元します。

## Damn itモード

「Damn it」をオンにしてバー本体を横へドラッグすると、そのバーと開始日時が同じか後ろにあるバーを全行からまとめて移動します。表示範囲外のバーも対象です。

- 個別PJでは、そのPJ内のバーだけを動かし、ダイヤモンドは保持します。
- `all` では全PJの後続バーと、同じ基準日時以降のダイヤモンドを動かします。
- `all project name` では選んだPJの最も早いバー開始を基準に、全PJの元のバーとダイヤモンドへ同じルールを適用し、集約表示を更新します。

1時間・日は稼働セル単位、月・Qは暦月単位、週はドラッグ先までの日付差で移動します。以前に開始したバーや基準より前のダイヤモンドは動かしません。

ドラッグ中はプレビューし、離すと確定します。Esc、ポインターの取消、ウィンドウのフォーカス喪失で取消できます。前のバーとの重複やPJ期間を超える移動は確定せず通知します。まとめ移動はUndo/Redo各1回で復元できます。モードは再読み込み時にオフへ戻ります。

## 保存・バックアップ・出力

同じブラウザ・プロファイル・オリジンのIndexedDBへ、編集後に自動保存します。「保存」で即時保存もできます。プライベートブラウズやブラウザのデータ消去による保存内容の消失に備えて、JSONでバックアップを保管してください。

通常のPNG・SVG・XLSX・JSONは、現在の横スクロール位置から表示期間分と全行を書き出します。途中のセルでスクロールが止まった場合は、左端にかかるセルを含めます。期間の両端をまたぐバーは範囲内へ切り詰めます。プレビューで余白・16:9配置・PNG解像度を調整できます。

「全データをバックアップ」は全期間の元データを保存します。個別PJならそのPJ、一覧なら全PJが対象です。JSON読み込みでは新しいIDで復元するため、既存PJは上書きしません。通常の一覧JSON出力は、表示範囲を1つのチャートとして保存します。

読み込みは10MBまで、個別チャートは500行まで、表示期間は1〜240です。PNGは64メガピクセルまたは一辺32767px、XLSXは16,384列を超える場合にエラーを表示します。表示期間や画像倍率を小さくして再出力してください。

作業フォルダの `projects/`・`project-data/`・`backups/`・`exports/` はGit管理から除外しています。JSON・PNG・SVG・XLSXも除外し、アプリの設定JSONと `assets/` の画像は例外として管理します。ブラウザ内のPJ自動保存先と、これらの保管用フォルダは別です。

## 言語

上部の `English` / `日本語` ボタンで、操作UIと日付ラベルを切り替えます。入力済みのPJ名・項目名・補足・バーのラベルは翻訳せず、そのまま保持します。選択した言語は同じブラウザに保存します。

## ランチャー

先に[クイックスタート](../README.md#クイックスタート)の依存パッケージをインストールしてください。

macOSでは `GanttDamn.app` をダブルクリックすると、ターミナルでサーバーを起動し、既定ブラウザを開きます。ランチャーはアプリのフォルダ内に置いたままDockへ追加できます。

Ubuntuでは `npm start` または `bash GanttDamn.sh` で起動します。既定ブラウザの自動起動には `xdg-open` が必要です。アイコン付きランチャーは配置先で次を実行して生成します。

```sh
npm run desktop:linux
```

生成された `GanttDamn.desktop` をファイルマネージャーから起動します。アプリの移動後は再生成してください。Ubuntuへコピーする場合、Macの `node_modules` を流用せず、その環境で依存パッケージをインストールします。

サーバーは `127.0.0.1:4317` を使用します。別のアプリが使用中なら終了を促して停止します。開発サーバーも使用中のポートを避けて自動変更しません。終了は起動したターミナルで `Ctrl+C` を押します。

## データ形式の補足

JSONのスキーマバージョンは1です。`visibleStartDate` はPJ開始日、`visiblePeriodCount` は表示期間、`projectEndDate` は終了日を表します。バーの終了日時 `endDateExclusive` はその日時を含みません。時間データはタイムゾーンを付けないローカル日時（例：`2027-01-01T08:00`）で保存します。

詳しくは[データモデル](../src/domain/model.ts)、[読み込み検証](../src/domain/validation.ts)、[表示範囲の出力処理](../src/domain/displayWindow.ts)を参照してください。
